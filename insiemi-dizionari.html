Insiemi (set)

Contenitori mutabili, non ordinati, di elementi univoci e immutabili (numeri, stringhe, tuple; non liste o dizionari). Su elementi unici sono molto più veloci delle liste nelle ricerche. 

cast = {"Luigi", "Gumbys", "Spiny"}
cast = set(["Luigi", "Gumbys", "Spiny"])
vuoto = set()               # {} crea un dizionario!
print("Luigi" in cast)
for actor in sorted(cast):  # ordine alfabetico
    print(actor)

Esempi: parole uniche e controllo ortografico

def clean(string):
    result = ""
    for char in string:
        if char.isalpha():
            result = result + char
    return result.lower()

words = set()
for line in open("nurseryrhyme.txt"):
    for w in line.split():
        words.add(clean(w))
print(len(words))

Dizionari

Coppie chiave → valore. Le chiavi sono uniche e immutabili; i valori sono di qualsiasi tipo. Mantengono l'ordine di inserimento. 

contacts = {"Fred": 7235591, "Mary": 3841212}
contacts["John"] = 4578102         # aggiunge
contacts["John"] = 2228102         # modifica
print(contacts.get("Tony", "missing"))
if "Tony" in contacts:
    print("trovato")
fred = contacts.pop("Fred")        # elimina e restituisce
for key in sorted(contacts):
    print(key, contacts[key])
for key, val in contacts.items():
    print(key, val)
copia = dict(contacts)             # contacts2 = contacts è un alias

Struttura Sequenza Mapping

  • Frequenze: count[nome] = count.get(nome, 0) + 1.
  • Matricola → nome: {123456: "Mario Rossi"}.
  • Scacchi: chiave tupla (1,3), valore "Re".

person = {"firstName": "John", "lastName": "Doe", "birthdate": 1971,
          "city": "New York", "profession": "Student"}

def extractRecord(infile):
    record = {}
    line = infile.readline()
    if line != "":
        fields = line.split(":")
        record["country"] = fields[0]
        record["population"] = int(fields[1])
    return record

Ordinamenti avanzati

lista.sort() modifica la lista; sorted(lista) ne crea una nuova. Aggiungi reverse=True per l'ordine decrescente.

Tipo nella lista Ordinamento
int, float numerico
complex impossibile (TypeError)
str lessicografico (Unicode)
list, tuple primo elemento diverso

from operator import itemgetter
studenti = [{"nome": "Ada", "cognome": "Rossi", "matricola": 3},
            {"nome": "Bob", "cognome": "Bianchi", "matricola": 1}]
studenti.sort(key=itemgetter("matricola"))
studenti.sort(key=itemgetter("cognome", "nome"))

# sort stabile: prima la chiave meno importante
studenti.sort(key=itemgetter("nome"))
studenti.sort(key=itemgetter("cognome"))

insiemi = [{1, 2, 3}, {1}, {4, 5}]
insiemi.sort(key=len)      # funzione SENZA parentesi
coordinate = [(3, 4), (1, 1), (0, 2)]
coordinate.sort(key=lambda p: p[0] + p[1])

best = max(studenti, key=itemgetter("matricola"))
print(studenti, insiemi, coordinate, best)

Strutture complesse

Indice analitico: dizionario termine → set di pagine. 

index = {}
righe = ["python 3", "set 10", "python 7"]
for line in righe:
    term, page = line.split()
    if term not in index:
        index[term] = set()
    index[term].add(int(page))
for term in sorted(index):
    print(term, sorted(index[term]))

Esempi guidati: dati senza duplicati e record

Un set è la scelta naturale quando l’ordine non conta e vuoi sapere quali elementi distinti compaiono. Convertire una sequenza in un insieme elimina i duplicati; applicare sorted solo alla stampa produce un ordine leggibile senza modificare la natura non ordinata del set. 

testo = "la rana salta la rana nuota"
parole = set(testo.split())
print(sorted(parole))
print("parole uniche:", len(parole))

Un dizionario rappresenta invece una relazione chiave-valore. Il metodo get permette di fornire un valore iniziale quando la chiave non esiste: questo rende semplice contare frequenze senza dover controllare ogni volta la presenza della parola. 

frequenze = {}
for parola in "blu rosso blu verde blu".split():
    frequenze[parola] = frequenze.get(parola, 0) + 1
print(frequenze)

Per ordinare record complessi usa key. La chiave può essere una funzione lambda che estrae il campo da confrontare; con una tupla puoi combinare più criteri, per esempio voto decrescente e nome crescente.
