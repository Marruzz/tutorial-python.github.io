if/elif/else, condizioni, while, for, sentinelle, nidificati, Monte Carlo, BlackJack.

4.7 Decisioni: if, else, elif

quantita = 6
totale = 12.0
if quantita >= 5:
    totale = totale - totale * 10 / 100
elif quantita < 0:
    print("Dato non valido")
else:
    print("Nessuno sconto")
print(totale)

L'indentazione (4 spazi) decide quali righe appartengono al blocco; i due punti aprono il blocco. Con elif si sceglie tra più di due possibilità: parte solo il primo ramo vero.

4.10 I quaderni: tutto insieme

SOGLIA_SCONTO = 5
PERCENTUALE_SCONTO = 10

prezzo = float(input("Prezzo di un quaderno: "))
quantita = int(input("Quantità: "))

if prezzo < 0 or quantita < 0:
    print("Dato non valido")
else:
    totale = prezzo * quantita
    if quantita >= SOGLIA_SCONTO:
        sconto = totale * PERCENTUALE_SCONTO / 100
        totale = totale - sconto
    print(f"Da pagare: {totale:.2f} euro")

4.11 Cicli while

n = 3
while n > 0:
    print(n)
    n -= 1
Output
3
2
1

La condizione è controllata prima di ogni giro; se non cambia mai, il ciclo è infinito (Ctrl+C per fermarlo). Va bene anche per cicli che dipendono da un evento.

4.14 Somma, conteggio, media, sentinelle

Pattern: inizializza somma = 0 e conteggio = 0, aggiorna nel ciclo, calcola la media dopo, evitando divisioni per zero. La sentinella è un valore speciale che segnala la fine dei dati quando non si sa quanti ne arriveranno.

somma = 0
conteggio = 0
voto = float(input("Voto (-1 per finire): "))
while voto != -1:
    somma += voto
    conteggio += 1
    voto = float(input("Voto (-1 per finire): "))
if conteggio > 0:
    print(f"Media: {somma/conteggio:.2f}")

4.16 Elaborare stringhe con i cicli

testo = "Ciao Mondo"
vocali = 0
for c in testo.lower():
    if c in "aeiou":
        vocali += 1
print(vocali)

Per trovare tutte le corrispondenze scorri senza break; per la prima usa break; per l'ultima aggiorna una variabile a ogni trovata.

4.19 Esempio finale: BlackJack semplificato

Informazioni da ricordare: punteggio del giocatore e se vuole un'altra carta.

import random
punti = 0
risposta = "s"
while risposta == "s" and punti < 21:
    carta = random.randint(1, 10)
    punti += carta
    print("Carta:", carta, "- Totale:", punti)
    if punti < 21:
        risposta = input("Un'altra carta? (s/n) ")
print("Sballato!" if punti > 21 else f"Ti fermi a {punti}")
