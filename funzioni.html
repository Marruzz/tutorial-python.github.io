Funzioni (P5)

Definizione, parametri, return, scope, main, raffinamenti successivi.

Funzioni come scatole nere

Una funzione è una sequenza di istruzioni con un nome. Si invoca passando argomenti e restituisce un valore. Come utente ti servono solo le specifiche, non l'implementazione.

price = round(6.8275, 2)
print(price)
Output
6.83

Un solo valore restituito: per più valori si usa una lista o una tupla. Moduli utili: string, math, random, statistics, os.path, csv, json; i moduli esterni si installano da PyPI con pip install.

Definire e collaudare

def cubeVolume(sideLength):
    volume = sideLength ** 3
    return volume

result1 = cubeVolume(2)
result2 = cubeVolume(10)
print("Un cubo con lato 2 ha volume", result1)
  1. L'argomento inizializza il parametro (come sideLength = 2).
  2. Si esegue il corpo.
  3. Il risultato torna al punto di chiamata.

Se il programma contiene solo la definizione, non accade nulla: serve la chiamata.

Passaggio dei parametri

Gli argomenti (parametri attuali) possono essere costanti, variabili o espressioni; le variabili parametro (formali) sono variabili distinte, inizializzate col valore dell'argomento.

AttenzioneModificare un parametro numerico dentro la funzione non cambia la variabile originale: viene passata una copia. Evita di modificare i parametri, introduci una variabile nuova.
def addTax(price, rate):
    tax = price * rate / 100
    return price + tax
total = 10
newPrice = addTax(total, 7.5)   # 10.75, total resta 10
print(total, newPrice)

Documentare con docstring

def cubeVolume(sideLength):
    """Computes the volume of a cube.
    :param sideLength: the length of a side of the cube
    :return: the volume of the cube
    """
    return sideLength ** 3

Posizionali, nominali, default, *args

def myComplex(real=0.0, imag=0.0):
    return (real, imag)

print(myComplex(3, 5))               # posizionali
print(myComplex(imag=5, real=3))     # nominali, qualsiasi ordine
print(myComplex())                   # valori di default

def myFun(arg1, *argv):
    print("First argument:", arg1)
    for arg in argv:
        print("Next argument through *argv:", arg)
myFun("Hello", "Welcome", "to", "Politecnico")

I posizionali precedono sempre i nominali; *args raccoglie un numero variabile di argomenti posizionali.

Valori restituiti

return termina subito la funzione e passa il valore a chi l'ha chiamata. Per più valori restituisci una tupla (return x, y).

def cubeVolume(sideLength):
    if sideLength >= 0:
        return sideLength ** 3
    else:
        return 0
AttenzioneTutti i rami devono restituire un valore, altrimenti Python restituisce None e si ottiene un errore a runtime. In alternativa usa una sola variabile volume e un unico return finale.

Implementare una funzione: i passi

  1. Descrivi cosa fa.
  2. Elenca gli input.
  3. Determina i tipi di parametri e ritorno.
  4. Scrivi lo pseudocodice.
  5. Implementa il corpo.
  6. Collauda come unità isolata.

Funzioni senza valore di ritorno

def boxString(contents):
    n = len(contents)
    if n == 0:
        return          # termina subito
    print("-" * (n + 2))
    print("!" + contents + "!")
    print("-" * (n + 2))

boxString("Python")

Senza return viene restituito None.

La funzione main

def main():
    result = cubeVolume(2)
    print("A cube with side length 2 has volume", result)

def cubeVolume(sideLength):
    return sideLength ** 3

if __name__ == "__main__":
    main()

Il blocco if __name__ == "__main__" esegue main() solo in modalità standalone, non quando il file è importato come modulo. Una funzione va definita prima di essere eseguita: main può citarne altre definite dopo, purché la chiamata a main() sia in fondo.

Funzioni riutilizzabili

def readIntUpTo(high):
    """Chiede un intero tra 0 e high, ripetendo finché è valido."""
    value = int(input("Enter a value between 0 and " + str(high) + ": "))
    while value < 0 or value > high:
        print("Error: value out of range.")
        value = int(input("Enter a value between 0 and " + str(high) + ": "))
    return value

hours = readIntUpTo(23)
minutes = readIntUpTo(59)

Ambito di visibilità (scope)

TipoDove viveNote
Localedentro la funzione (parametri inclusi)invisibile alle altre funzioni
Globalefuori da tutte le funzioniper modificarla serve global
balance = 10000
def withdraw(amount):
    global balance
    if balance >= amount:
        balance = balance - amount
withdraw(2500)
print(balance)
ConsiglioEvita le globali: usa parametri e valori restituiti. Due variabili locali di funzioni diverse possono avere lo stesso nome (result) senza conflitti.

Raffinamenti successivi

Scomponi un problema complesso in problemi più semplici finché sai risolverli. Esempio: scrivere un numero in lettere (274 → two hundred seventy four).

def intName(number):        # usa le tre funzioni sotto
def digitName(digit):       # "", "one", "two", ...
def teenName(number):       # "ten", "eleven", ...
def tensName(number):       # "twenty", "thirty", ... + digitName
  • Funzioni brevi (se superano uno schermo, spezzale).
  • Traccia l'esecuzione: una riga per step, una colonna per variabile.
  • Usa stub: funzioni provvisorie che restituiscono un valore semplice per collaudare presto.

Sommario

  • Gli argomenti inizializzano le variabili parametro.
  • return termina e restituisce il risultato.
  • I commenti spiegano scopo, parametri e ritorno.
  • Le variabili locali non sono visibili altrove.

Esempi dalle slide: progettare funzioni

Una funzione ben progettata riceve dati tramite parametri, calcola un risultato e lo restituisce con return. Per esempio, il volume di una piramide quadrata dipende dall’area della base e dall’altezza; separare il calcolo in una funzione rende il programma facile da riusare e da collaudare.

def pyramid_volume(height, base_length):
    base_area = base_length ** 2
    return base_area * height / 3

print(f"{pyramid_volume(6, 4):.2f}")

Gli argomenti possono essere posizionali, nominali o omessi quando esiste un valore predefinito. Con *args una funzione raccoglie in una tupla tutti gli argomenti posizionali oltre il primo: è utile per funzioni che devono accettare un numero variabile di valori.

def mostra(primo, *altri):
    print("Primo:", primo)
    for elemento in altri:
        print("Altro:", elemento)

mostra("Hello", "Welcome", "to", "Politecnico")

Quando una funzione legge input, valida il valore nello stesso punto in cui lo acquisisce. In questo modo il resto del programma può assumere che il dato sia corretto e si riduce la duplicazione dei controlli.
